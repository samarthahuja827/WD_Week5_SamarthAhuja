# Student Management System
Live Link: https://samarthahuja827.github.io/WD_Week5_SamarthAhuja/

## Project Overview
The Student Management System is a responsive web application built using HTML, CSS, and JavaScript to manage student records easily.

## Features
- Add, edit, and delete student records.
- Search students by name.
- Filter students by course.
- Sort students by marks.
- Validate student information.
- Calculate total students and average marks.
- Save records using browser Local Storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser.
4. Add students and try the available features.

## Project Structure
- `index.html` — webpage structure.
- `style.css` — styling and responsive layout.
- `script.js` — application functionality.

## Learning Outcomes
This project helped me practise JavaScript variables, functions, arrays, objects, array methods, DOM manipulation, event handling, form validation, and Local Storage.
